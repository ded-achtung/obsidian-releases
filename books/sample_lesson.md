## Операции над списками (учим из проработанных примеров)

Развернуть список переворачивает его порядок.
Пример: разверни [1, 2, 3] = [3, 2, 1]
Ещё пример: разверни [4, 5] = [5, 4]

Удвоить список умножает каждый элемент на два.
Пример: удвой [1, 2, 3] = [2, 4, 6]
Пример: удвой [5, 1] = [10, 2]

Сумма списка складывает его элементы в одно число.
Пример: сумма [1, 2, 3] = 6
Пример: сумма [4, 5] = 9
