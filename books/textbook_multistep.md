# Учебник: многошаговые задачи

Сначала простые операции (из примеров), затем задачи, где из входа нужно получить
цель — и для этого требуется НЕСКОЛЬКО операций подряд. Шаги не названы: их надо
спланировать самому.

## Примеры — что делают операции

Пример: разверни [1, 2, 3] = [3, 2, 1]
Пример: разверни [4, 5] = [5, 4]
Пример: удвой [1, 2, 3] = [2, 4, 6]
Пример: удвой [5, 1] = [10, 2]
Пример: сумма [1, 2, 3] = 6
Пример: сумма [4, 5] = 9
Пример: максимум [3, 1, 2] = 3
Пример: максимум [5, 9, 2] = 9

## Задачи — получи цель из входа (нужно несколько шагов)

Задача: получи 12 из [1, 2, 3]
Задача: получи [6, 4, 2] из [1, 2, 3]
Задача: получи 9 из [4, 5]
