# Урок: преобразования сеток

Сетка — прямоугольник клеток с цветами-числами; ноль означает пустую клетку.
Ниже каждое новое слово вводится показом (вход → выход), а затем сложные
операции определяются через уже известные слова.

## Отражение

Отражение переставляет клетки слева направо, как в зеркале.

отражение [[1, 2], [3, 4]] → [[2, 1], [4, 3]]
отражение [[5, 0, 6]] → [[6, 0, 5]]

## Переворот

Переворот переставляет строки сверху вниз.

переворот [[1, 2], [3, 4]] → [[3, 4], [1, 2]]
переворот [[7], [8]] → [[8], [7]]

## Кадр

Кадр обрезает сетку до прямоугольника занятых клеток.

кадр [[0, 0], [0, 7]] → [[7]]
кадр [[0, 0, 0], [0, 5, 5], [0, 0, 0]] → [[5, 5]]

## Увеличение

Увеличение рисует копию сетки в каждой её занятой клетке.

увеличение [[2, 0], [0, 2]] → [[2, 0, 0, 0], [0, 2, 0, 0], [0, 0, 2, 0], [0, 0, 0, 2]]
увеличение [[3, 3], [0, 3]] → [[3, 3, 3, 3], [0, 3, 0, 3], [0, 0, 3, 3], [0, 0, 0, 3]]

## Узор

узор это сначала кадр потом увеличение
