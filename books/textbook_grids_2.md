# Продвинутый урок: составные преобразования

Этот урок опирается на базовые слова (отражение, переворот) — без них
определения не собрать. Показов здесь нет: новые операции вводятся только
через уже известные слова.

## Поворот на 180 градусов

поворот это сначала отражение потом переворот

## Синонимы

зеркалирование значит отражение

## Открытый вопрос для любознательных

инверсия это сначала обращение потом отражение
