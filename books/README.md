# Книги (данные для обучения)

Положи сюда книги — система будет учиться по ним. Поддерживаются:

- **PDF** (`.pdf`) — текст извлекается через PyMuPDF;
- **Markdown / текст** (`.md`, `.markdown`, `.txt`).

Файлы, начинающиеся с `_` или `.`, игнорируются.

Запуск обучения и честной оценки:

```bash
pip install -e .            # ядро
pip install pymupdf         # для чтения PDF
python run_book.py          # обучение + held-out bits-per-character
```

`sample_mathematics.md` — небольшой встроенный математический текст для проверки
конвейера. Чем больше и однороднее твои книги, тем сильнее модель обходит
бейзлайны (на маленьком тексте — скромно, но уже бьёт unigram на отложенной части).
