# Дополнительные операции: падение и остов

Падение опускает занятые клетки вниз их столбцов, как под тяжестью.

падение [[5, 0], [0, 0]] → [[0, 0], [5, 0]]
падение [[3, 3], [0, 0]] → [[0, 0], [3, 3]]

Остов обрезает сетку до прямоугольника занятых клеток.

остов [[0, 0], [0, 7]] → [[7]]
остов [[0, 0, 0], [0, 5, 5], [0, 0, 0]] → [[5, 5]]
