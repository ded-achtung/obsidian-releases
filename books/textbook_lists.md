# Учебник: операции над списками

Учебник из трёх частей: проработанные ПРИМЕРЫ (что делает операция), ТЕОРИЯ
(когда её применять — по каким словам задачи распознать) и ЗАДАЧИ для решения.
Важно: в задачах НЕ называется операция напрямую — её надо ВЫБРАТЬ по смыслу.

## Примеры — что делают операции

Пример: разверни [1, 2, 3] = [3, 2, 1]
Пример: разверни [4, 5] = [5, 4]
Пример: удвой [1, 2, 3] = [2, 4, 6]
Пример: удвой [5, 1] = [10, 2]
Пример: сумма [1, 2, 3] = 6
Пример: сумма [4, 5] = 9
Пример: максимум [3, 1, 2] = 3
Пример: максимум [5, 9, 2] = 9

## Теория — когда применять правило

сумма нужна когда просят итог или общее
максимум нужен когда просят наибольшее
разверни применяй когда нужно перевернуть порядок
удвой применяй когда нужно увеличить вдвое

## Задачи — реши, выбрав правило по смыслу

Задача: найди общее [10, 20, 30]
Задача: наибольшее [4, 2, 9, 1]
Задача: перевернуть порядок [1, 2, 3, 4]
Задача: удвой и общее [1, 2, 3]
