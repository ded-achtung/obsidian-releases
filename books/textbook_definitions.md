# Учебник: определения новых операций

Часть материала — не примеры, а ОПРЕДЕЛЕНИЯ: новая операция объясняется через уже
известные («сначала то, потом это»). Система выучивает её из текста и пользуется ею.

## Примеры — базовые операции

Пример: удвой [1, 2, 3] = [2, 4, 6]
Пример: удвой [5, 1] = [10, 2]
Пример: сумма [1, 2, 3] = 6
Пример: сумма [4, 5] = 9
Пример: разверни [1, 2, 3] = [3, 2, 1]
Пример: разверни [4, 5] = [5, 4]

## Определения — новые операции через известные

обработай это сначала удвой потом сумма
итог это сначала разверни потом сумма

## Задачи — используя определённые операции

Задача: обработай [1, 2, 3]
Задача: итог [10, 20, 30]
