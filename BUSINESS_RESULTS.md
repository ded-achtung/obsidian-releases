# Бизнес-бенчмарк: как система ВИДИТ бизнес (предсказание + правило)

Смена домена с ARC на табличный бизнес. Система — табличный предиктор + индуктор
правил на чистом numpy (не LLM), поэтому проверяем то, что ей по силам: **предсказание
поведения клиента** и **извлечение интерпретируемого правила** «как она видит бизнес».

## Датасет

ISLR **Default** (`data/Default.csv`, из `statsmodels get_rdataset('Default','ISLR')`):
10 000 клиентов, предсказать ДЕФОЛТ по кредитке из `balance` / `income` / `student`.
Классика, бизнес-смысл, **сильный дисбаланс — 3.3% дефолтов** (как реальный отток/дефолт).

## Воспроизвести

```bash
python run_business.py
```

## Результат (held-out 30%)

**1. Accuracy обманчива (честная установка).** Бейзлайн «предсказывай 'нет дефолта'» →
accuracy **96.6%**, но recall дефолтов **0%**. На дисбалансе смотрим AUC и recall.

**2. Классификатор системы** (линейный softmax = логрегрессия):

| метрика | значение |
|---|---|
| AUC | **0.961** |
| accuracy | 97.1% (обманчива) |
| recall@0.5 / precision | 27% / 70% |
| recall@порог-под-баланс / precision / balanced-acc | **93% / 19% / 90%** |
| веса (стандартиз.) | **balance +2.63**, income +0.03, student −0.33 |

**3. Интерпретируемое правило (OneR) — «как система видит бизнес»:**

> **ЕСЛИ balance > 1288 → дефолт** — на held-out: balanced-acc **90%**, recall **95%**, precision 18%.

## Что это значит — честно

- **Система видит этот бизнес ВЕРНО по сути:** дефолт определяется **балансом**, а не
  доходом. И линейная модель (вес balance ≫ income/student), и **независимая** индукция
  правила указывают на `balance > ~порог`. Это правильный бизнес-драйвер (совпадает с
  известной структурой ISLR Default).
- **Честные метрики:** AUC 0.96 высок, но accuracy 97% обманчива из-за дисбаланса —
  реальная картина в AUC/recall. Правило даёт высокий recall (95%) ценой точности (бизнес
  сам выбирает порог по цене ошибки).
- **Граница та же, что на ARC:** это **статистическая зависимость из данных** (как у
  логрегрессии), не понимание бизнеса. Система не знает, ЧТО такое дефолт и почему он
  важен; она находит, КАКОЙ признак его предсказывает. «Видит» = «коррелирует и выделяет
  драйвер», не «понимает».

Итог: на табличном бизнесе система работает на уровне честной логрегрессии и даёт
читаемое правило, верно указывающее драйвер — полезно и проверяемо. Но «видит бизнес»
здесь = распознаёт статистический драйвер, а не осмысляет его (тот же разрыв
«рассуждать/считать vs мыслить/понимать», что измерен на ARC).
