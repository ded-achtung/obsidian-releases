# Думающая система (brain-inspired)

Исследовательский проект: **думающая система, которая со временем всё лучше понимает материал и обучается по нему** — построенная на принципах мозга (brain-inspired), а **не** как обёртка над языковой моделью.

Принципы:
- Интеллект рождается из **архитектуры** (восприятие + память + предсказание + рассуждение + обучение во времени), а не из предобученной LLM.
- Накопление понимания — через **внешнюю структурированную память** (эпизодическая / семантическая / процедурная).
- Домен-агностичность; обучаемые нейрокомпоненты.

## Документы

- [`research/brain-inspired-thinking-system.md`](research/brain-inspired-thinking-system.md) — обзор подходов (JEPA, CLS/replay, HTM/SDR, active inference, Thousand Brains), предлагаемая архитектура, метрики, риски, план MVP.

## MVP: предиктивный цикл (шаг 1 дорожной карты)

Замкнутый цикл **предсказание → ошибка → обучение** на одном потоке:

```
поток → энкодер → предиктор (следующий латент) → ошибка учит предиктор
      → опыт в эпизодическую память → replay дообучает предиктор
```

Запуск:

```bash
pip install -e .          # ядро (numpy)
python run_mvp.py         # демонстрация: ошибка предсказания падает со временем
python run_mvp.py --plot  # + PNG-график (нужен extras: pip install -e '.[viz]')
pytest                    # тесты (pip install -e '.[dev]')
```

На синтетическом потоке ошибка предсказания падает ~на 99 % и обходит тривиальный
baseline (persistence) — измеримый признак «понимание растёт со временем».

> Честно про планку: «~99 %» привязано к лёгкому почти-бесшумному потоку (`noise=0.02`)
> и считается от СЛУЧАЙНОГО старта сети; при `--noise 0.5` улучшение ≈ 67 %. Persistence
> — слабейший baseline: zero-параметрическая линейная экстраполяция `2·zₜ₋₁ − zₜ₋₂` (без
> обучения) почти равна обученной модели. Поэтому `run_mvp.py` теперь печатает и эту
> честную планку (`обходит лин. экстрап.`), и предупреждение про зависимость от шума.

## Шаг 2: любопытство через активный вывод

Агент перестаёт быть пассивным — он САМ выбирает, какой канал наблюдать, чтобы
максимизировать прирост информации (минимизировать ожидаемую свободную энергию).
Эпистемическую ценность канала оцениваем как **learning progress** (устойчивое
падение ошибки), пропущенный ЭВРИСТИЧЕСКИМ гейтом «падение велико относительно
дисперсии канала» (а не строгим тестом значимости — ошибки автокоррелированы). Это
**смягчает**, а не «решает», проблему «шумного телевизора»: внимание к белому шуму
ниже случайного, но не ноль.

```bash
python run_step2.py   # любопытство vs случайное внимание на 4 каналах
```

Среда — 4 канала разной выучиваемости (easy / medium / hard / noise). Устойчивый
по сидам результат: любопытство **концентрирует** внимание на ещё-выучиваемом
канале (типичный куррикулум easy→medium→hard) сильнее равномерного, тогда как
случайное внимание размазано равномерно:

```
фаза        easy  medium   hard  noise
средняя     8.4%   38.0%  48.3%   5.4%   ← одна (средняя) фаза ОДНОГО сида, не среднее
```

> Честно про числа: строка выше — средняя ФАЗА одного прогона (seed 0), а не усреднение.
> Эффект реальный, но скромнее «итога»: суммарное внимание к шуму ≈ 19–23 % против ≈ 25 %
> у случайного (а в РАННЕЙ фазе любопытство может тратить на шум даже больше случайного,
> пока не накопит данные для гейта). Запустите `run_step2.py` — он печатает все фазы и итог.

> Примечание про `pymdp`: библиотека реализует точный дискретный POMDP-вариант
> ожидаемой свободной энергии. У нас модель мира непрерывная (латентная), поэтому
> active-inference выбор реализован нативно поверх неё, а `pymdp` оставлен швом
> для дискретной формулировки (см. `policies/active_inference.py`).

## Шаг 3: консолидация / непрерывное обучение без забывания

Доказываем, что система **не забывает** старое, обучаясь новому. Последовательность
из нескольких различных задач (режимов) предъявляется по очереди одной общей модели
мира. Сравниваем по образцу Complementary Learning Systems:

- **naive** — без повторения (память сбрасывается на каждой задаче) → катастрофическое забывание;
- **replay** — CLS-консолидация (эпизодическая память хранится между задачами и переигрывается) → забывания почти нет.

```bash
python run_step3.py   # матрица задача×задача + ACC / forgetting / BWT / FWT
```

Устойчивый по сидам результат — replay фактически обнуляет забывание:

```
метрика                    naive   replay
forgetting (рост ошибки)  0.38    -0.00    ← replay помнит старые задачи
ACC (финальная ошибка)    0.29     0.005
```

Метрики — по Lopez-Paz & Ranzato (GEM, arXiv:1706.08840). Сейчас это experience
replay (хранимые эпизоды); швы под развитие — generative replay (синтез прошлого
без хранения) и регуляризация (EWC).

## Реальные данные: обучение по книгам (все языки + код)

Система читает книги из `books/` (PDF через PyMuPDF; Markdown/txt; файлы кода
`.py/.js/…`) и учится предсказывать следующую единицу текста — та же машинерия
предсказание→ошибка→память/replay. По умолчанию — **байтовый уровень (UTF-8,
фиксированный словарь 256)**: это УНИВЕРСАЛЬНОЕ представление, любой язык и любой
код кодируются одинаково, без языковой настройки. Честная метрика — **bits-per-byte
на отложенной (held-out) части** против тривиальных бейзлайнов.

```bash
pip install -e . && pip install pymupdf
python run_book.py                     # байтовый уровень (по умолчанию), книги из books/
python run_book.py --books mybook.pdf  # один файл; --level char — символы Unicode
```

Реальные результаты (held-out — данные, которых модель не видела):

| данные | метрика | uniform | unigram | МОДЕЛЬ |
|---|---|---|---|---|
| книга «Python для непрограммистов» (рус.+код, 156 КБ) | bits/char | 7.40 | 5.91 | **4.25** ✅ |
| смесь англ. + рус. + Python-код (49 КБ) | bits/byte | 8.00 | 5.46 | **4.91** ✅ |

Модель **бьёт unigram на held-out** → выучила контекст (слова, синтаксис кода), а
не просто частоты, и обобщает; генерация переключается между языками и кодом в
одном словаре. На больших книгах разрыв растёт; для качества — больший/субсловный
вариант (швы есть). Текстовый энкодер — обучаемый эмбеддинг (не random-projection).

## Единый контур и действие во внешнем мире

- **Единый когнитивный контур** (`run_agent.py`): один агент читает реальные тексты,
  сам выбирая источник (любопытство), предсказывает байты, по surprise находит
  аномалии и запоминает с консолидацией — учится 5.3→2.2 бит/байт; без консолидации
  забывает (BPC ×15 хуже); на лету находит опечатку в новом коде.
- **Действие в мире** (`run_world.py`): агент в незнакомом лабиринте строит модель
  мира и доходит до цели — 794 → 24 шага (оптимум), ~50× лучше случайного.
- **Обучаемая JEPA-модель мира** (`run_latent_world.py`): на зашумлённых наблюдениях
  учит инвариантные коды клеток и предсказывает последствие действия со 100% — основа
  планирования в непрерывных/шумных мирах (вместо таблицы).
- **Частичная наблюдаемость / POMDP** (`run_partial.py`): агент видит только локальный
  обзор, ведёт байесовскую веру, локализуется (14 гипотез → 1) и доходит до цели в
  100% против 57% у безпамятного.
- **Язык → цель → поведение** (`run_language.py`): цель задаётся словами; классификатор
  понимает невиданные формулировки (100% held-out) и агент идёт к понятой цели.
- **Объединённый агент** (`run_unified.py`): один агент действует в зашумлённом
  частично-наблюдаемом мире по языковой команде — обученное восприятие + байесовская
  вера + грунтинг языка вместе; восприятие 100%, навигация к языковой цели 8/8.
- **Иерархическая память** (`run_hierarchical.py`): эпизод → семантика (ориентиры по
  betweenness) → навыки (маршруты); 4 ориентира вместо 40 клеток, ~10 навыков на 60
  целей, план по ~2 ориентирам вместо ~5 шагов.
- **GPU/torch-бэкенд** (`run_torch.py`): torch-предикторы — drop-in замены numpy тем же
  интерфейсом (автоопределение CUDA); та же система масштабируется на GPU.

### Структура

```
thinking_system/
  encoders/    — сенсорный ингест (random-projection; шов под JEPA-энкодер)
  predictors/  — предиктор: MLP (шаг 1) + ансамбль для оценки неопределённости
  memory/      — эпизодическая память (кольцевой буфер + replay)
  streams/     — домен-агностичный пассивный поток (шаг 1)
  envs/        — управляемая среда: action→obs, мультиканальная (шаг 2)
  policies/    — выбор действия: active inference (любопытство) + baseline
  tasks/       — последовательность различных задач/режимов (шаг 3)
  consolidation/ — непрерывное обучение через replay, CLS (шаг 3)
  text/        — ингест книг (PDF/MD/код), словарь (байты/символы), датасет
  predictors/  — …+ SymbolicPredictor (следующий символ/байт) для текста
  metrics/     — ошибка, метрики любопытства, continual-learning (ACC/BWT/FWT)
  core/        — Experience, PredictiveLoop, ActiveInferenceLoop
  agent/       — CognitiveAgent (единый контур), ActingAgent, BeliefAgent (POMDP)
  world/       — GridWorld, LatentWorldModel (JEPA), PartialGridWorld (POMDP)
  language/    — грунтинг команды на естественном языке в цель
books/         — сюда кладутся книги (PDF/MD) для обучения
run_mvp/step2/step3.py   — демонстрации шагов 1–3
run_book.py              — обучение по реальным книгам (held-out BPC)
run_agent.py             — единый когнитивный контур
run_world/latent_world/partial/language.py — действие в мире и его расширения
show_learned/show_code/use_learned.py — что выучила и как использует модель
tests/                   — тесты (34)
```

Каждый компонент — абстрактный интерфейс + реализация. «Швы» под следующее:
иерархическая (эпизод→семантик→навыки) память, дискретный active inference
(pymdp / RxInfer), GPU/torch-бэкенд тем же интерфейсом.

## Рассуждение на реальном ARC (честный, воспроизводимый замер)

Индукция программ над словарём перцептивных примитивов проверена на **настоящем ARC**
(датасет ARC-AGI) с **held-out** оценкой: «решено» = программа, выведенная из train-пар,
ВЕРНО предсказывает отложенную test-пару (а не просто подошла к данным примерам).

```bash
python run_arc.py            # сам скачает ARC-AGI в .arc_cache, 400 задач, синтез из данных
python run_arc.py --no-synth # только фиксированный словарь (baseline)
python run_arc.py --growth   # + проверка: рост библиотеки = охват или эффективность
```

**Фиксированный словарь (`--no-synth`): 22/400, 0 overfit, 8 многошаговых**; повторяющиеся
комбо `keep_largest ▸ bbox` ×2 и `flip_h ▸ flip_v` ×2 система абстрагирует сама. Честные
границы этого режима:
- **рост библиотеки = ЭФФЕКТИВНОСТЬ, не охват**: семьи комбо начинают решаться на глубине 1
  (14→18), но охват на глубине 2 не растёт (22→22, +0); **глубина 3 тоже +0** — потолок
  задаёт ШИРИНА примитивов, не глубина поиска.

**Выход за рамки словаря — синтез примитивов из данных (по умолчанию): 29/400 (+7).** Это
[`reasoning/synthesis.py`](thinking_system/reasoning/synthesis.py): по train-парам задачи
система СИНТЕЗИРУЕТ операции, которых в seed нет (`colormap*` — выученная таблица замены
цветов; `upscale*`/`tile*`/`downscale*` — масштаб с фактором из данных), и проверяет их на
отложенной test-паре. +7 задач решены **операциями, выведенными из самих данных**, а не
заложенными заранее — первый реальный шаг к тому, чтобы язык РОС из задач, а не только
рекомбинировался. (Перенос идеи `dsl_growth` — «не выводится → синтезируй примитив» — с
навигации на сетки.) Честно: это несколько семейств параметрических операций, а не «любое
новое понятие»; синтезированный примитив проверяется как ЦЕЛОЕ преобразование, поэтому
решает на глубине 1 сам по себе.

## Статус

Работают: шаги 1–3 (предсказание / любопытство / консолидация), обучение по
**реальным данным** (книги PDF/MD, все языки + код на байтах), **единый
когнитивный контур** (учится И использует), и **действие во внешнем мире** —
навигация (модель мира + активный вывод), обучаемая **JEPA-модель мира** для
зашумлённых наблюдений, **частичная наблюдаемость** (POMDP, байесовская вера) и
**язык → цель → поведение**. 34 теста.

Плюс: **объединённый агент** (восприятие+вера+язык в шумном POMDP-мире),
**иерархическая память** (эпизод→семантика→навыки) и **GPU/torch-бэкенд** тем же
интерфейсом. 41 тест.

Это инженерный синтез из проверенных по отдельности компонентов на чистом numpy
(torch — опционально для масштаба), без LLM. Дальше: обучаемая JEPA-память в
объединённом агенте, большие torch-модели на GPU для связной генерации.
