# Аудит проекта и внесённые исправления

Аудит охватил ядро (предиктивный цикл, любопытство, метрики, предикторы), рассуждения
(индукция/библиотека/сетки/восприятие), язык, агентов, мир, память, текст и тесты,
а также честность заголовочных заявлений (README + сообщения коммитов). Числа
проверялись запуском демо; корректность — отдельными репро-скриптами.

**Итог проверки:** инженерия по большей части корректна (бэкпроп MLP/symbolic проходят
градиент-чек; поиск программ проверяет ВСЕ примеры; Q-learning без утечки награды;
BPE/dataset/буфер/спектральные горлышки корректны). Основные проблемы были в
**завышенных формулировках** и в нескольких реальных багах восприятия/роста библиотеки.
Тесты: было `162 passed, 1 failed (fitz)`; стало **`162 passed, 3 skipped`**.

## Что исправлено

### Целостность заявлений / воспроизводимость
- **C1. ARC-числа невоспроизводимы → ТЕПЕРЬ ВОСПРОИЗВОДИМЫ.** Добавлен `run_arc.py`: сам
  скачивает ARC-AGI и делает честный held-out замер на 400 настоящих задачах. Проверено:
  **22/400 решено (0 overfit, 8 многошаговых)**, повторяющиеся комбо `keep_largest ▸ bbox`
  ×2 и `flip_h ▸ flip_v` ×2 — числа из исходного коммита подтвердились на реальных данных.
  Рост библиотеки даёт эффективность (глубина 1: 14→18), но +0 к охвату; глубина 3 тоже +0
  (потолок — ширина примитивов). `run_grow_solutions.py` дополнительно помечен как
  СИНТЕТИЧЕСКАЯ иллюстрация механизма (без невоспроизводимых ARC-чисел), с честным
  сравнением планок и held-out проверкой корректности.
- **C2. Нет held-out на сетках → «решено» = совпало с одним примером.** Доку `induce`
  дополнена предупреждением: «решено» = согласовано с ДАННЫМИ примерами, не гарантия
  обобщения; для проверки нужна отложенная пара (как в `run_benchmark.py`).
- **H2. Слабый baseline / 99% зависит от шума.** В `core/loop.py` добавлена честная
  планка — линейная экстраполяция `2·zₜ₋₁ − zₜ₋₂` (без обучения); `tracker` считает
  `linear_final`/`beats_linear`; `run_mvp.py` печатает её и предупреждение про
  зависимость улучшения от уровня шума. README дополнен той же оговоркой.
- **H3. Рост библиотеки = эффективность, не охват.** Доку `library_learning` уточнена;
  демо показывает обе планки (глубина 1 и 2 сырого seed).
- **M7. README-строка «средняя».** Помечено, что это одна фаза одного сида, не среднее;
  добавлены честные итоговые числа по шуму.
- **H4/H5. Язык «читает смысл».** В docstrings `reader/understanding/facts/study/`
  `definitions/morphology` добавлены разделы «ГРАНИЦЫ»: это разбор по фиксированным
  шаблонам над закрытым словарём, ломается на перефраз/синоним/падеж/порядок слов;
  морфология — лоссовая эвристика (не сводит даже «перевернуть/перевернул» к одной
  основе, ложно склеивает «стол»→«сто»).

### Реальные баги
- **H1/L3. Гейт любопытства.** SE считается по половинам своего размера (корректно при
  нечётном окне); docstring и README честно говорят, что это ЭВРИСТИЧЕСКИЙ гейт по
  дисперсии (надёжен против белого шума, но не строгий тест для автокоррелированного
  дрейфа — нужен Newey–West/Mann–Kendall).
- **M1. `restore_symmetry`** больше не портит уже-симметричные сетки (ранний возврат,
  если узор уже h+v-симметричен) — устранён ложный «диагональный» окклюдер.
- **M2. `grow_from_solutions`** не падает `StopIteration` на программах «любого решателя»
  с чужими примитивами: `_by_name` безопасен, комбо с неизвестными именами пропускаются.
- **M3. `sleep`** считает число РАЗНЫХ решений с комбо (а не вхождения): повтор внутри
  одного решения больше не выдаётся за «встретилось дважды».
- **M4. Цена абстракции** = сумме цен её шагов (а не 1.0) → честный MDL/Оккам-учёт.
- **M5. Утечка состояния между прогонами.** `PredictiveLoop.run`/`ActiveInferenceLoop.run`
  сбрасывают накопленное состояние в начале.
- **M6. `SyntheticStream`** детерминирован при повторной итерации (свежий ГСЧ шума по seed).
- **L1. `steps_to_halve_error`** возвращается в пространстве шагов (поправка на лаг `window-1`).
- **L2. `final_error`** помечен как in-sample (не held-out).
- **L4. `rot90`** — задокументировано направление (по часовой); **`fill_holes`** заливает
  замкнутую область ЦВЕТОМ ОКРУЖЕНИЯ, а не глобальным max-цветом.
- **L5. Тест `fitz`** использует `pytest.importorskip` → skip, а не fail без extra `[text]`.
- **L6. `run_hello_world`** исполняет сгенерированный код с минимальным набором builtins.
- **Парсер причинности** («X приводит к Y») теперь даёт ребро X→Y, а не X→предлог.

## Развитие: выход за рамки фиксированного словаря (synthesis.py)

Аудит показал, что на ARC система решала только короткие КОМПОЗИЦИИ из ~23 руками
закодированных примитивов: глубина 3 и «рост библиотеки» давали +0 к охвату (потолок —
ширина словаря). Чтобы потолок перестал быть зафиксирован заранее, добавлен
`reasoning/synthesis.py`: по train-парам задачи СИНТЕЗИРУЮТСЯ операции, которых в seed нет
(`colormap*` — выученная замена цветов; `upscale*`/`tile*`/`downscale*` — масштаб с
фактором из данных), и проверяются на отложенной test-паре. Это перенос идеи `dsl_growth`
(«не выводится → синтезируй примитив из данных») с навигации на домен сеток.

Замер (training, held-out): **22/400 → 29/400 (+7)**. Все 7 новых задач решены примитивами,
выведенными ИЗ ДАННЫХ (имена с «*»), а не заложенными заранее, — первый реальный рост
ВЫРАЗИТЕЛЬНОСТИ, а не рекомбинация. Честно о границах: это несколько семейств
параметрических операций (не «любое понятие»); синтезированный примитив проверяется
end-to-end, поэтому решает на глубине 1 сам по себе. Тесты: `tests/test_synthesis.py` (6).
Запуск: `python run_arc.py` (синтез по умолчанию) vs `python run_arc.py --no-synth`.

## Отклонено как ложные срабатывания (проверено)
Replay-буфер корректен (FIFO-кольцо); `sample` с возвращением — документированное штатное
поведение; спектральные «горлышки» реально находят мост (на barbell узел-мост — ранг 1).
В исправления не вошли.
